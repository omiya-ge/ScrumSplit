# ScrumSplit

中綴じ・スクラム製本（二つ折りの紙を重ねた冊子）をばらしてスキャンした PDF を、元の 1 ページずつの PDF に戻す静的 Web アプリです。
処理はすべてブラウザ内で行われ、ファイルはどこにも送信されません。

## 使い方

1. スキャンした PDF をドロップ（またはクリックして選択）
2. 次の設定を選ぶと、最初の 4 ページのプレビューがその場で更新されます
   - **製本の向き**: 左とじ（横書き）/ 右とじ（縦書き）
   - **スキャンした面**: 外側が上（表紙側の面から）/ 内側が上（中央の見開きの面から）
   - **スキャンの向き**: 読める向き / 逆向き（180°）
   - 詳細設定: 裏面だけ上下が逆、紙の順番を逆にする、横向きスキャンの補正（90°）
3. 「ダウンロード」または「名前を付けて保存…」（Chrome / Edge のみ）で保存

### 想定しているスキャン

- 1 枚の紙の表と裏を続けてスキャンしたもの（両面スキャン）。PDF の 1 ページ = 紙の片面（見開き 2 ページ分）
- 「外側が上」なら一番外側の紙から、「内側が上」なら一番内側の紙から順に並んでいるもの
  （順番が逆の場合は詳細設定の「紙の順番を逆にする」）

画像を再圧縮せずに元のスキャンをそのまま切り出すので、画質は劣化しません。

## GitHub Pages で公開する

ビルド不要です。リポジトリを GitHub に push し、
**Settings → Pages → Build and deployment** で「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` を選べば公開されます。

## ローカルで動かす

ES Modules を使っているので、`file://` ではなく HTTP サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## ファイル構成

- `index.html` / `style.css` / `app.js` — UI、プレビュー、PDF の書き出し
- `imposition.js` — スキャンの各半分が何ページ目にあたるかの計算
- `vendor/` — [pdf.js](https://github.com/mozilla/pdf.js) 4.10.38（Apache-2.0）、[pdf-lib](https://pdf-lib.js.org/) 1.17.1（MIT）
